# AmarPath — Authority Road Hazard & Pothole Management Portal

The companion web management dashboard for **AmarPath (Smart Road Damage Detection System)**.

## Key Features
- **Live GIS Hazard Mapping:** Interactive map powered by OpenStreetMap (OSM) standard, humanitarian, and cycling layers.
- **Civic Light Design System:** Modern, high-contrast, accessible interface designed for municipal road maintenance authorities.
- **KPI Metrics Ribbon:** Real-time metrics tracking detected defects, critical zones, repair assignments, and resolved road segments.
- **OpenStreetMap Nominatim Street Search:** Forward and reverse geocoding for any street, road, or intersection across Bangladesh.
